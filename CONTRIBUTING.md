# Contributing

Questions and focused improvements are welcome. Open an issue before changing a
schema, status meaning, or required control. Such changes affect downstream CI
and need an explicit compatibility decision.

Run `npm test`, `npm run typecheck`, and `npm run check:examples` before opening
a pull request. Include tests for success, boundary, and failure behavior.

Follow the [Code of Conduct](CODE_OF_CONDUCT.md). Contributions are accepted
under Apache-2.0.
